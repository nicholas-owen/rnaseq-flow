BULK RNA-SEQ : A FAIR APPROACH

rnaseq-flow

From FASTQ to differential expression, splicing, fusions and pathways, in one run that records how it got there.

Nicholas Owen · UCL Advanced Research Computing · version 1.9.1 · November 2026

Thanks for having me. I'm Nicholas, from ARC. This is rnaseq-flow, a bulk RNA-seq pipeline I've been building in Nextflow. It has changed a lot since I last showed it: it now goes from raw reads all the way to differential expression, splicing, transcript usage, fusions and enrichment in a single run, and every run leaves a record of what it did and who did it. The current release is 1.9.1, with its own Zenodo DOI. I'll cover what it is, how it works, and why it is worth using wherever you run your analysis: a laptop, a desktop, a cluster, the cloud or a TRE.
