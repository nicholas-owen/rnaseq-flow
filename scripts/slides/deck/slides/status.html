rnaseq-flow · UCL ARC

Where are we? Everything on the left is released, as 1.9.1, with a concept DOI on Zenodo that resolves to every version. The checks that run in CI today are static: channel topology and process arity, the report's R code and the modules, plus a stub run that exercises both the genome and the pseudo-aligner routes and each of the launch refusals. What that doesn't prove is that a process produces what the next one expects, and that's where the last round of review found its problems. So next is per-process tests with nf-test, starting with the processes where a wrong answer is silent: rMATS, DESeq2, edgeR, tximport and featureCounts. Then the protocol gaps against nf-core, UMI handling and rRNA removal, because a UMI library processed without UMI handling gives wrong numbers. Then merging re-sequenced libraries, and later duplicate marking and deeper QC.
