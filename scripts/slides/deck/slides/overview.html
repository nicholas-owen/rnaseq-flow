OVERVIEW

One samplesheet in, a whole analysis out

A Nextflow DSL2 pipeline that takes raw reads to tested, annotated, reported results, and records how it got there.

INPUT

A four-column CSV

FASTQ · or a count matrix

ENGINE

Nextflow, containerised

docker · singularity · conda

OUTPUT

Results and two reports

MultiQC · Quarto

RECORD

A folder that explains itself

manifest · RO-Crate · reproduce/

rnaseq-flow · UCL ARC

In one sentence: one samplesheet in, a whole analysis out. The input is a four-column CSV: sample, read 1, read 2 and condition. If you already have counts, from GEO or a collaborator, a count matrix can enter instead and skip straight to differential expression. Every tool runs in its own container, so the only things to install are Nextflow, Java and a container engine. What comes out is a results folder, a MultiQC report for QC and a Quarto report for the analysis, and a record: a run manifest, a Workflow Run RO-Crate, and a reproduce folder beside every analysis that draws figures. It is the downstream sibling of refdata-flow: same Nextflow style, same SGE profile.
