GETTING STARTED

Three commands from nothing to results

# 1 · references from Ensembl, pinned

nextflow run main.nf --download_refs \

  --download_species homo_sapiens ...

# 2 · the index for one aligner

nextflow run main.nf --build_indices \

  --aligner star --genome_fasta ... --gtf ...

# 3 · the analysis

nextflow run main.nf --input samplesheet.csv \

  --aligner star --star_index ... --gtf ... \

  -profile docker

rnaseq-flow · UCL ARC

Getting started is three invocations of the same entry point. The first fetches a genome, annotation and gene sets from Ensembl, pinned to a release, with a metadata file recording where they came from. The second builds the index for your aligner, or all four at once. The third runs the analysis. If you've never used it, start with the yeast example: it fetches a six-sample dataset and walks through all four aligners, and a 12 megabase genome indexes in about two gigabytes, so it runs on a laptop with the test_yeast profile. And if you're already using refdata-flow, the two fit together: the genome and annotation are just paths, so you pass in what refgenie seek prints. One caveat there: the organism check reads a metadata file only rnaseq-flow's own download writes, so set the organism yourself.
