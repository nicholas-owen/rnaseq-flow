rnaseq-flow · UCL ARC

A lot of our RNA-seq is on human samples, and some of it has to live in a Trusted Research Environment. As configured, the pipeline can't run there: several containers are provisioned at run time by Nextflow's Wave service, which needs the internet. So there is a complete offline bundle on Zenodo: 27 Singularity images, about seven gigabytes, the nf-prov plugin that writes the RO-Crate, and a tre config that switches Wave off and pins every image locally. You download it outside, bring it in by whatever route your environment allows, and run with the tre profile, alone or with SGE. The bundle has its own DOI, separate from the pipeline's, and the v1.8.0 bundle is the one that works with the current release. References and gene sets need fetching outside first.
