rnaseq-flow · UCL ARC

The same pipeline runs on a laptop, a desktop, a shared server, a cluster or the cloud; what changes is one profile. Docker is the usual choice on a laptop or workstation. Singularity or Apptainer is for shared infrastructure where Docker isn't available. Conda works with no container engine at all, slower, and it needs network access to solve environments. The SGE profile is tuned for SGE clusters: it requests memory per core the way SGE expects, rounded up, uses node-local scratch, and routes the one job that needs a high-memory node, a splice-aware HISAT2 index for human or mouse, to those nodes automatically. The TRE profile runs from the offline bundle, which is the next slide. For SLURM or another scheduler, or for a cloud batch service, Nextflow supplies the executor: copy the SGE config as a starting point or pass a few lines with -c. No cloud profile ships with the pipeline yet.
